# Usage

1. Open the app, tap **Choose folder**, and pick the folder you want to share
2. Tap **Start**; the IPv4 / IPv6 addresses and a QR code appear above
3. Any device on the same LAN can open that address in a browser
4. Tap an address to copy it; tap the QR icon to show the code for scanning
5. In **Settings** you can toggle Show IPv6 address / Allow directory listing / Anti-crawler / CAPTCHA, and change the port, enable HTTPS, or ban IPs

> Tip: put an `index.html` in the folder and it will be served by default; otherwise a file list is shown according to your settings

## FAQ

- **Can't open it?** Make sure the phone and the computer are on the same Wi-Fi (same subnet)
- **Port already in use?** Change it in **Settings → Port** (1024 - 65535)
- **No IPv6 address?** Your router may have IPv6 disabled, or your ISP does not provide it
- **Browser warning with HTTPS?** That is expected for a self-signed certificate — just continue

# 使用方法

1. 打开 App,点【选择文件夹】,选中你想共享的目录
2. 点【启动】,上方会显示 IPv4 / IPv6 地址与二维码
3. 同一局域网内的设备用浏览器打开该地址即可访问
4. 点地址即可复制;点二维码图标可展开二维码供扫码
5. 【设置】里可开关:显示 IPv6 地址 / 允许文件浏览 / 反爬虫 / 验证码验证,并可修改端口、切换 HTTPS、封禁 IP

> 提示:目录里放一个 `index.html`,访问时会默认打开它;没有的话按设置决定是否显示文件列表

## 常见问题

- **打不开?** 确认手机和电脑在同一个 Wi-Fi(同一网段)
- **端口被占用?** 到【设置 → 服务端口】换一个(1024 - 65535)
- **IPv6 地址不显示?** 路由器可能没开 IPv6,或运营商没有下发
- **用 HTTPS 时浏览器报警告?** 自签名证书的固有提示,选择继续访问即可
